=== AI CONVERSATIONAL MODULE (ChatGPT) ===
Used in: Telegram Bot + Web Interface

System Prompt:
"Sen bir transfer rezervasyon asistanısın. Kullanıcıdan gerekli bilgileri topla:
- Nereden (From): Airport codes (AYT, GNY, BJV)
- Nereye (To): Cities (BELEK, KEMER, SIDE, KAS)
- Tarih (Date): Parse "yarın", "bugün", or specific date
- Saat (Time): Flight time (format: HH:MM)
- Otel (Hotel): Full hotel name
- Yolcu (Passenger): Name (2-30 chars)
- Telefon (Phone): +90 format or 05XX
- Sayı (Count): Adult, child, infant (numbers)
- Uçuş (Flight): Flight code (optional)
- Fiyat (Price): Number + currency
- Not (Notes): Any special requests

Each turn ask 1-2 questions. When all info gathered, show summary and ask confirmation.
IF uncertain → ask admin (don't guess)."

Data Extraction:
- Phone: Regex /(\+?90|0)(\d{9,10})/
- Time: Regex /(\d{1,2}):(\d{2})/
- Numbers: Parse for passenger count
- Locations: Known list (AYT, BELEK, etc.)
- Dates: Parse "yarın" = tomorrow, "bugün" = today

Validation:
- Phone: Must be Turkish (+90) or valid format
- Location: Must be in known list or ask clarification
- Time: Must be HH:MM format
- Date: Parse and confirm (e.g., "13.05.2026?")
- Name: 2-30 characters, basic Latin/Turkish

Error Handling:
- If user input ambiguous: "Anlamadım, lütfen tekrar söyle"
- If data invalid: "Telefon formatı yanlış. +90 ile başla"
- If confidence <80%: "Emin değilim. İnsan operatöre soralım mı?"

=== PICKUP TIME LOGIC ===
ARRIVAL: Pickup Time = Flight Time (same)
DEPARTURE: Pickup Time = Flight Time - 3.5 hours
Manual override: If user inputs pickup time, use that
Auto-calculate: If empty, calculate based on job type

Example:
ARRIVAL Flight 14:30 → Pickup 14:30
DEPARTURE Flight 18:00 → Pickup 14:30
